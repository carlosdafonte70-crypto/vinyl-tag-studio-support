THE ESSENTIALS

Get started in minutes.

Simple steps for a smoother tagging workflow.

01

Open your music

Select Choose Folder and grant access to the folder containing your audio files. Vinyl Tag Studio displays the supported tracks in the list.

02

Edit metadata

Select one or multiple tracks. Edit fields such as Title, Artist, Album, Year and Genre. Use Extended Tags & Audio Info for extra metadata.

03

Save with confidence

Updates are saved with progress feedback. The app creates original-file backups before writing, and offers undo for the last saved change during the active session.

⌘

Tip: Batch editing

Use ⌘A to select all loaded tracks, then enter a shared value (for example, Album or Genre). Fields showing < keep > remain unchanged.

COMMON QUESTIONS

Answers, without the guesswork.

Why can’t I see my music files?

Use Choose Folder and select the folder containing the files you want to edit. On macOS, Vinyl Tag Studio needs your permission to access each folder. If you moved your files or an external drive changed, choose the folder again.

How do I change tags on several songs at once?

Choose multiple rows in the track list with Shift or Command, or press ⌘A to select all. Enter the shared value in the Tag Editor. Leave fields showing < keep > unchanged if you want to preserve each track's original value.

Can I edit album cover artwork?

Yes. Select your tracks and use the artwork controls below the Tag Editor to change, export, or remove embedded cover art. Test changes on copies of important recordings first.

How can I undo a change or find backups?

Use ⌘Z to undo the most recent saved change while the app session is running. You can also find backup files via Actions → Show Original File Backups in Finder.

How can I rename files from their tags?

Select the desired tracks and choose Convert → Tag → Filename. For custom naming patterns, use Tag → Filename (Custom Format) and review the preview before confirming.

How do I change the appearance?

Open Appearance from the menu bar or the palette button. Choose from Studio Blue, Emerald Night, Amethyst, Copper Glow, and Graphite.

Does the app require a cloud account?

No account is required to use the local music-tag editor. The folders and files you choose stay under your control. To contact support, use the form below.
